# Security

The PinSay extension asks for powerful permissions (see [Permissions and why](README.md#permissions-and-why)),
so we take reports about it seriously.

## Reporting a vulnerability

Email **support@pinsay.dev** with "Security" in the subject: what you found, the extension version
(`chrome://extensions` → PinSay), the browser, and the steps to reproduce. Please do not open a public issue
or post details publicly before we have answered.

We confirm receipt within 3 working days and tell you what we will do and when.

## Scope

- This extension (the code in this repository, as published on the Chrome Web Store, Edge Add-ons and
  Firefox Add-ons).
- The PinSay service it talks to (`app.pinsay.dev`) — report those issues to the same address.

Only the latest published version is supported.
